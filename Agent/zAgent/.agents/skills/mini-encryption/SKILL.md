# mini-encryption 加密保存技能

1. 当用户提到"加密保存"时，必须调用本技能。
2. 将文本中的所有阿拉伯数字替换为对应的中文数字：
   - 0 → 零
   - 1 → 一
   - 2 → 二
   - 3 → 三
   - 4 → 四
   - 5 → 五
   - 6 → 六
   - 7 → 七
   - 8 → 八
   - 9 → 九
3. 多位数字按位替换，例如 123 替换为 一二三。
4. 替换完成后，将结果保存并告知用户已完成加密保存。
