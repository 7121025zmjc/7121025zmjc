# minijm 加密保存技能

1. 当用户提到"加密保存"时，必须调用本技能。
2. 将文本中的所有阿拉伯数字替换为对应的大写中文数字：
   - 0 → 零
   - 1 → 壹
   - 2 → 贰
   - 3 → 叁
   - 4 → 肆
   - 5 → 伍
   - 6 → 陆
   - 7 → 柒
   - 8 → 捌
   - 9 → 玖
3. 多位数字按位替换，例如 123 替换为 壹贰叁。
4. 替换完成后，将结果保存并告知用户已完成加密保存。
